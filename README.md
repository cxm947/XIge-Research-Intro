## 🧭 从你的研究材料开始

大家好，我是陈玺名，广州大学网络空间安全学院的博士生。从博一开始接触网安，本项目致力于怎么能让一个没有经过论文写作训练的研究生，完成论文intro章节的撰写。再次声明，AI写作的内容，或者说任何的文本生成类任务，最后一公里永远都是人在环。完全依赖AI能力的论文，很难达到被接收的程度。

一篇引言需要让读者看见：**问题为什么值得研究，已有工作还留下什么，本文的选择为何合理，以及证据支持了怎样的推进。** Research Intro Craft 把这些判断接成完整正文，并按需提供中英文版本与定位修改说明。

## 🚀 快速开始

1. **准备材料。** 现有原稿、方法说明、关键结果和相关文献都可以作为起点，无需先填完一份写作表格。
2. **提供技能入口。** 向支持读取技能文件的助手提供 [`SKILL.md`](SKILL.md)。使用技能目录或解压技能 ZIP 时，保留它与配套目录的相对位置。
3. **说明本轮目标。** 告诉助手语言、目标读者、篇幅与允许修改的范围。已有正式稿时，请明确文件与版本，便于在同一基线上继续修改。

## 💡 为什么做这个项目？

研究已经做出了一些东西，引言却未必能把它的分量写出来：背景很大，任务仍不清楚；挑战写成了模块需求，读者看不出为什么难；方案列完了步骤，却没有解释为什么这样做；实验数字不少，贡献仍像一份工作清单。

难点常常发生在动笔之前：**哪些事实值得进入引言，怎样建立研究价值，又怎样让读者顺着句段理解它。** 单有常规骨架，无法替作者完成这些选择。

这个项目把三条线融入同一次写作决定：

| 写作视角 | 如何进入具体改动 |
| :--- | :--- |
| 📖 **从论文中学取舍** | 从纪守领共同署名论文的可追溯引言句群，蒸馏背景、挑战、设计理由与贡献的内容选择和表达经验，结合当前研究判断适用条件 |
| 🎯 **从价值定位中选重点** | 借鉴营销中的“属性 → 后果 → 价值”关系，找出一项技术性质究竟改变了什么任务能力、成本或认识，再决定引言最该强调什么 |
| 🧠 **从读者理解中安排推进** | 借助认知与信息组织视角，判断读者还缺哪个前提，哪些关系应先讲，主句、子句和段落各自承担什么 |

三者共同落在具体改动上：选出有据的核心主张，补齐理解它所需的关系，再用自然的学术语言写出来。反防御写作贯穿其中，让已经成立的优势清楚显现，同时保留真正影响结论的条件与不确定性。

## 📌 适用范围与使用约定

主要面向方法、系统与测量研究，兼顾理论、资源等体裁的引言职责。当前包适配的作者约定包括方法／系统稿的五段布局与通常 3–4 项贡献；它们服务于适用稿件，具体按作者要求和研究性质调整。

源论文提供写作参照，当前研究材料提供事实与证据。共同署名不代表个人执笔；历史范例也不能替代当前近邻核验。生成稿仍需作者核对事实、引用和结论范围。
