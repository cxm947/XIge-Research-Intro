# 同一研究，两条主线怎样改变选材

本例依据纪守领共同署名的 [How IoT Re-using Threatens Your Sensitive Data](https://nesa.zju.edu.cn/download/lpy_pdf_sp23.pdf)，展示一次原创的引言重组。材料属于这篇源研究，不是用户的新研究；下面的作者正文与贡献次序也不是源文翻译。示例沿测量论文的常规骨架展开，供主线尚未确定时按需参照。

选中心时，让任务的重要后果、相对同任务合理近邻的增加、以及直接证据共同约束同一项研究答案。大数字不能替代另一个任务的答案，应用价值也不能补足缺少的近邻比较；比较不足时先写已实现的改变，不把独特性当作定论。机制、方法与范围测量都可成为中心，取决于本稿要交付的判断。营销的参照与价值关系只提供类比启发，学术依据仍须来自本研究及相关文献；[迁移边界](discipline-sources.md)另列。

## 两个都有依据的中心

同一研究包含用户调查、固件中的数据收集分析，以及配置受控设备后开展的清除与取证。它支持两种不同的主要认识：

- **A：需要保护哪些数据，这些数据处于怎样的保护状态。** 固件中的收集行为与受测设备中的明文状态提供范围和保护依据；用户调查交代类别认识及保护预期。这条主线让读者认识设备转交时可能带走什么数据，并在总体层面对照用户认识与技术样本。
- **B：执行清除操作后，哪些数据仍能提取，结果怎样随方法及实现而变。** 清除前后的预置标记检查、同一设备不同重置方式的结果，以及存储与清除实现的分析，可以共同支持这条主线。它让读者判断一种已执行操作是否取得了预期效果。

| 作者选择 | A：数据范围与保护状态 | B：操作效果与实现条件 |
| --- | --- | --- |
| 开头先展开的观察 | 设备可能收集的数据类别及保护状态，用户认识交代其使用情境 | 操作完成后的标记残留，以及同设备不同重置方式的差别 |
| 引入哪些已有工作与做法 | 转交前清除建议，以及关于设备数据收集、保护和用户认识的既有研究 | 转交前清除的建议、将敏感数据移至云端的既有方案，以及本地处置操作与存储写入方式 |
| 首先报告的结果 | 收集类别与保护状态，及其与用户认识的总体对照 | 所测方法的残留结果；同一设备软、硬重置后的不同表现 |
| 贡献的顺序 | 数据暴露认识 → 支撑认识的收集分析 → 处置效果及建议 | 清除效果的经验认识 → 支撑比较的取证研究 → 使用情境及改进依据 |

本例以源文 RQ3“处置方法是否有效”为主问题，因此选择 B：前半引言展开操作后状态、存储关系及同设备的方法差异，结果首先回答标记是否仍可提取。A 的数据类别和认知材料交代处置对象及使用情境。问卷中“是否执行操作”回答行为问题，受控取证回答操作执行后的效果，不能互相替代。

**何时应改选 A。** 源文 §VI-D 同时希望政策制定者明确可以存储哪些敏感信息、这些信息应怎样保护。若本稿以这一用途为中心，就应前移类别与保护状态，使 A 成为首要答案；残留结果不能独自确定保护对象，B 随后补充再利用时的处置效果。该节谈到的回收方清除责任则更直接由 B 回应。这个同源反例说明选择随任务改变，不说明 B 普遍优于 A；若稿件保留原研究的综合目标，两种答案也可共同服务于再利用任务。

## 选择 B 后的作者正文

IoT 设备的再次使用，使数据保护延伸到设备离开原用户之后。路由器、摄像头等设备为维持网络连接和其他服务，可能保存网络配置、账户凭据等信息。当设备被转售、借出或回收，这些信息也可能随硬件进入新的使用环境。再利用前的数据清除因此承担着具体任务：在保留设备使用价值的同时，防止后续持有者获取原用户留下的敏感信息。

已有建议要求用户在转交设备前删除个人信息，已有研究也提出将敏感数据转移至云端，以降低本地留存带来的风险。对于仍保存在设备上的信息，配置改写、页面上的软重置、按键触发的硬重置和固件升级提供了用户能够执行的处置途径。这些做法为再利用中的数据保护建立了实际基础；其效果还取决于操作后的数据状态，尤其是原有信息是否仍可从设备存储中提取。

理解这一效果，需要考察清除操作与存储实现的关系。采用磨损均衡写入的闪存文件系统可能把更新写入新的存储单元，并将旧单元标记为无效，旧内容则继续保留在存储中。清除实现是否进一步执行物理擦除，会影响后续能够提取什么。因此，对清除效果的研究既需要比较操作前后的数据状态，也需要检查与残留相关的存储和清除行为。

本文结合用户调查、固件分析与设备取证研究这一问题。调查交代常见设备及其处置情境；固件的数据收集分析帮助确定需关注的信息；设备实验以预置标记检查清除前后的数据状态，并进一步检查相关清除实现。取证发现，一些已执行操作仍留下可提取的标记。同一台 Phicomm 设备在硬重置后仍可提取测试标记，软重置后则未在所用取证流程中检出。进一步的实现分析发现，出现残留的设备同时采用磨损均衡文件系统和仅删除用户文件的清除方式。这些观察将清除效果落实到具体操作及其实现，为评价设备转交前的数据处置提供了经验依据。

本文的主要贡献如下：

1. 揭示所测设备上清除方法的残留差异，包括同一设备不同重置方式的不同结果，形成关于实际清除效果的经验认识。
2. 提供清除前后的标记取证比较，并将残留观察与相关实现联系起来，支撑具体设备和方法的效果评价。
3. 结合用户处置情境与设备数据分析，提出面向用户操作和厂商清除实现的改进建议。

## 这一重组改变了什么

两条中心保留的是不同的研究答案，所需的观察、已有依据和首要结果随之改变。B 的正文没有把认知调查缩成“用户不清除”的陪衬，也没有继续以数据收集规模为结果高点；它先说明可用处置途径，再引入读者判断操作效果所需的存储关系，最后让同设备的结果差异与第一项贡献呼应。这样的内容安排展示了价值定位与读者所需前提如何进入正文；其阅读效果仍需后续使用检验。

## 来源与必要条件

事实依据限于上述源论文：完整 Introduction（PDF 物理页 1–2）；受控设备研究及标记检查（§III-C，页 4–5）；伦理说明（§III-E，页 5–6）；用户认知与设备数据（§IV–V，页 6–9）；处置方法、同设备案例及实现分析（§VI，页 10–12，尤其页 11 Table VIII 后的讨论）；既有研究的分类（§VIII，页 13）。这里沿用源论文对前人工作的叙述，没有逐篇重核它引用的文献，也不据此提出新的文献空白或首次性主张。正文中的贡献顺序是本例的编辑选择，源论文并未以 B 单独统摄全部贡献。

使用这份示例时保留以下科学条件，条件说明不并入作者正文：

- 设备实验检验的是研究者预置的标记，未恢复真实旧用户的数据。查到残留支持对应测试信息仍可提取；未检出只表示该取证流程的结果，不能据此保证设备内所有信息均已安全擦除。源文还指出，加密会使部分信息无法恢复，扫描器不支持解密。
- A 对照的是问卷与固件、设备分析所呈现的认识和状况。样本不是逐个用户与其个人设备配对，不能写成个体认知误差的测量，也不能把调查比例直接与设备中的明文比例相减。
- 固件中的数据收集代码分析与清除实现分析承担不同任务。前者提示可能收集的类别，后者解释已观察到的残留条件；检测到收集代码不等于证实每台实际设备都保存了对应数据。
- 同设备案例和实现观察支持所测方法与条件下的比较。它们没有确立所有软重置均有效、所有硬重置均失效，也没有单独识别每种存储特征的因果效应。
