# 同一次内容选择中的价值与读者理解

先问这项事实改变什么任务能力，再问读者尚缺哪项关系才能接受它；用当前稿件的同一事实同时完成两件事。不要分别加一段价值口号和一段认知说明。

例如，[Diff-ID的完整引言](intro-source-maps/sj-9042a938b2.md)先让身份差异成为合理检测信号，再说明属性差异怎样掩盖它，随后改变比较条件。这项内容同时解释任务价值、保留必要推断前提，并为设计选择提供理由。准确来源路径以[图谱索引](intro-source-index.md)为准。

具体可读的源事实、保义表达和邻句选择见[三个成句案例](worked-choices.md)；需要改取材时先用[内容分支](choices/index.json)，已经定好同一命题时再用[语言操作](realizations/operations.md)。
