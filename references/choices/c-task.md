# C. 命名任务：说明必须完成的判断及其价值（4支）

先选本位置要建立的判断，再读所列来源的必要邻段和完整贡献集合。英文均为编辑抽象式，须换入本稿自己的事实后自然成文；同职责分支不是同义句。所列源句语法是来源事实，适用性与篇幅判断是编辑迁移。

语言实现：[L2](../realizations/operations.md#l2)。


### C1 必要性句绑定承担者、动作与后果

- 源：FreeEagle P3.S1。因果承接风险，形式主语把平台维护者的检测动作置于重点，目的不定式接阻止传播
- 选择与实现：“It is therefore important for [actor] to [task] before [downstream action], so that [supported consequence can be avoided].”
- 适用：真实工作流有明确责任与时点；没有该角色证据时改为对象／任务作主语，不虚构使用者
- 代价：一句绑定必要动作及后果，后续困难句再解释条件，不在首句堆所有挑战

### C2 问题句明确最终要知道什么

- 源：ORL-Auditor P2.S10。已知威胁名词化，how宾语问数据所有者如何判断嫌疑模型是否源自其数据
- 选择与实现：“These circumstances raise the question of how to determine whether [precise target relation] using [available observations].”
- 适用：研究输出是审计／辨识判断，而非改变系统行为。问题必须可测，不能扩大为法律或政策裁决
- 代价：较直接能力宣告多一点问题铺垫，适合任务尚未被共同接受的位置

### C3 给定已有产物，明确人的剩余工作

- 源：FirmRCA P3.S1–2。Given崩溃用例→分析者定位错误指令→该任务耗时
- 选择与实现：“Given [artifact], analysts must identify [target] to [practical purpose]. This requires [the nontrivial judgment developed next].”
- 适用：研究价值是让已有结果变得可操作，后文评价应能回答剩余工作是否减少
- 代价：保留输出与任务边界，不能因系统名高级就暗示自动完成后续修复

### C4 用不变量与失效行为定义成功判据

- 源：TextShield P2.S4–6支持对人仍有毒／对机器逃逸的任务不变量，字符实例后解释视觉相似与模型失败；“保留良性用途”的联合评价另据C2.S2及正文§5。两处支持不同关系，不能把后者倒灌进P2原句
- 选择与实现：“The task is to identify [harmful property] even when [surface changes], while preserving [the required legitimate behavior].”
- 适用：对象变形后其任务语义仍在，或两种性质须同时成立。需真实定义和共同评价支持
- 代价：必要时保留一个小例子，不把所有攻击变体列进任务定义
