# IPPO：参照数量减少之后的可比性与证据责任

准确来源是 Detecting Missed Security Operations Through Differential Checking of Object-based Similar Paths，共著者托管ACM CCS 2021会议排版稿，18物理页，完整引言在物理1–3页、印刷1627–1629页。[指定PDF](https://www-users.cse.umn.edu/~kjlu/papers/ippo.pdf)。指定版本与完整重建使用同一PDF字节；未与另行下载的ACM版本作字节等价声明。

本文件与 baseline-analysis.zh.md 保留的完整研究理解及57单元共同使用。既有任务理解和证据成熟度分析继续保留，21处新细化负责条件作用域、矩阵/焦点、指代、长度及具体备选。科学资格另在 evidence.zh.md，不用证据疑问偷偷改弱作者的句子。

## 一、价值先落在必要性判断，而不是漏了一行代码

P1先列安全操作种类，再给正确使用的收益、遗漏风险、引用占比和作者自己对Linux的观察。两项百分比不是同一研究同一分母；前置一致性框架连接的是现象，不应改写为据旧研究计算了新样本。数字之后继续列具体危害，使规模说明有现实意义。

P2.S1真正改换读者问题：危害严重虽然已知，检测困难仍在于操作是否对特定上下文必要。它不是把缺位本身等同漏洞。原因从句内部的是否问题为后续规则、复杂语义分析及oracle短缺建立动机；若只保留检测很难，后面的比较思路便没有足够来由。

多数交叉检查是强近邻，因为它用重复代码的行为降低直接语义理解成本。P2.S6把三个动作分开：发现多数采用操作，假定多数正确，再报告少数差异。P2.S7承认其能力后，P3才有资格批评这些前提何时失效。作者描述中的我们并非本分析对假设作正确性背书。

## 二、两套挑战有不同的论证位置

P3的三类问题属于旧判据前提：足够多的可比参照是否存在，规模化表征是否丢失关键片段，多数行为是否真能代表正确。它们不是待新方法逐个同名填入的三个模块。源中的四对一数字解释多数阈值所需样本关系，不是检测成绩；图示反例帮助读者理解单例为什么不能形成多数，而不是增加一个定量实验。

P4降低需要的参照数量，先交框架，再说对象相关语义相似时预期安全操作一致，随后报告潜在bug。其最外层依据陈述、嵌入条件及预期不能压成两个路径不一致就已证bug。也不能把只需一对相似路径写成完全不需要参照或任何两条都可以。

P5随即承认新任务：如何得到足以比较的对象路径对。旧画像用必须证明它们可比作概括，容易误读为源提供正式等价证明；本轮更精确地说以规则和分析建立所需可比性。这里的两种困难是语义/上下文判断与构造规模，和P3三种旧失效不同。因此第一挑战与第二挑战的常规指代必须局部解析，不能按全篇编号机械配对。

## 三、惯常句式的作用来自真实依赖

P4.S1的提出动作是语法主句，真正降低门槛的内容在关系从句；把主句当唯一重点会只剩工具名。P4.S2的观察又包含if条件与expected结论，语义焦点并不因嵌套就变成背景装饰。P4.S3则叠加给定相似对、两边操作有无差异、报告潜在问题三个层次，每个都改变读者能推出什么。

P5.S6用目的句接语义/上下文规则，S7用主题转换接规模处理。相近的地址问题句式服务不同职责，不应把全部写成一个泛称方法模块。S8用已给规则和技术作前置依据，再断言精确且可扩展的能力；保留源作者强度，同时不由able或precisely词语本身认证零误报。

前置目的、条件、参照和证据来源经常出现，但不对应一条固定的专家句法公式。它们在这里有效，是因为读者已经缺少相应前提；没有实际内容时增加这些形式只会制造虚假的连接。

## 四、长句保留判断层次，短句完成转换

P2的条件句较长，因为观察、信任假设和报告输出不能混合。P3.S9很短，却把失败类型从样本/表示转到多数真值。P5.S1短主题句先交构造难题，后面才拆语义与规模。P6.S6的分别配对跨句回指P6.S2项目次序，而非紧邻的运行时间/报告句；P6.S7代词所指补丁也依靠接受谓词和提交语境，不能只取最近名词。这说明精确回指是读者能读懂结果层级的条件。P6.S6的长结果句同时给项目分布与bug类型，若改成单总数可以缩短，但代价是读者失去异质项目和覆盖类型的信息。

三条贡献正文分别四、四、两句，长度差有内容理由。C1不仅重复已实现系统，还新交扩展/定制与未来开源；C2仍需说明为什么构造是贡献并同时承担精度/规模；C3只须回收前面已有数量的发现/修复。不能以统一字数或每条一行替代这些职责。

三个粗体短标题是名词/动名词式的类别提示，分别前景化系统、构造技术、发现与修复。它们有自己的修辞工作，但不是需要修成完整有限句的缺陷，也不能无声加入旧57句计数。P7贡献引导是逻辑组织单元，并非断言它在排版上另成自然段。

## 五、结果选择沿证据成熟度，而不是把大数当好结果

P6先交实现和四项目范围，再说明两种运行域，强调项目影响面。随后运行时间与754报告属于自动分析层；人工检查后分项目的新发现合计161；136属于提交补丁后的外部接受层。正文另有275个有效总bug，包含已有修复，它不能被不加说明地拿来替代新发现。

这个顺序让读者知道每个数字已接受哪一层检验。把754写成新漏洞会误计成果；把136写成全部新bug已经在所有部署中修复，会越过源状态。P6.S7的被动接受结构使外部主体及结果可见，C3.S2则保留多数已修复，不能为了简洁把most改成all。

P6.S8综合效果、可扩展性与可移植性。旧ledger所写迁移在此应理解为跨程序可移植性，不是机器学习中的跨模型迁移。总体结论依赖整段不同证据：分析时间不能独立证明候选全真，已发现数量不能独立证明任意程序可移植。

作者在引言选择新发现与维护者接受，正文则有误报、其他工具比较和反向互补分析。比较数字不是越强越应搬到引言；不同测试集合回答不同问题。这里有根据的编辑推断是，实地新发现和社区采纳更直接支持其补足旧判据盲区的价值。不能据这个取材解释声称作者有意隐藏任何数字或推断真实写作心理。

## 六、备选的范围和成本

每个局部项给源句及全引言的精确半开字符跨度、散列和未改内容原则；部分只是关系/限定的中文等义对应，不能因此算作一种新写作策略。七个整句变体另列，以报告归属、内容接口或组织变化为单位，保留预期、潜在、可能、能力和已完成程度。

压缩总数、删除一个例子或改选比较结果可以有用，但会改变取材，应另标成本。忠实转述不把源作者强主张统一弱化为可能有帮助，也不把候选规则提升成形式证明。评价资格不代替主文中的研究判断。

来源覆盖、哈希与有范围的独立审查只界定工作范围，不证明程序实验可复现性或未见新稿上的写作质量收益。
