## 任务及审计证据从何而来

任务是非侵入式、三粒度机器遗忘验证，审计服务器是否删除指定数据、删除数量是否足够。它不是提出更快的遗忘算法，也不是保证所有生产副本都已删除的密码学证明。模型方有训练/遗忘控制权；数据中介拥有原模型与遗忘后副本、目标/测试数据及计算资源，作为验证者；数据贡献者向中介提请求。无串通、交付同任务模型是场景假设。

“非侵入”指无需事前给数据植后门或水印。验证仍对白盒模型副本进行继续训练，提取梯度响应；量级验证还训练影子模型。不能由不植入标记推成只需预测API或无计算成本。引言法律及合约内容是论文设定动机，不是当下法域普适义务。

最直接遗忘是删数据重训，已有精确/近似方案减成本。验证近邻有后门标记、成员推断、距离度量和密码学/可信执行证明。引言重点比较侵入方案的安全/既有数据不可回溯标记问题；§II还承认非侵入及证明路线，故不宜把“首个整体框架”扩成首个任何遗忘验证。

三个失信行为建立必要证据阶梯：完全不做，部分做，同类同量但删错样本。类变化可排第一种，数量变化可识第二种，第三种即使前两项通过仍需目标样本级辨别。两规范性质（数据真实性、数量完整性）与三粒度不是表面数字对齐，而是对手能力递进。

## 全引言的段落推进

坐标说明：P/S为稳定的论证分析块及其句级单元，不与源文自然段一一对应；列表和独立排版的研究问题另在账本注明。以下分清分析归组与源文真实分段。

P1三句法律删除权→模型中影响消除→研究关注。P2五句先给重训直接答案，再成本与精确/近似框架。其“精确=分块重训”是以SISA一类方法概括的介绍，不是精确遗忘唯一数学定义。P3八句引数据不足、外包中介、多模型流转、政策/合约、贡献后仍可撤回、模型副本可得。长角色说明有实质作用：最后一句保证后面梯度审计有访问基础。可压缩重复合约铺陈，但删掉模型副本条件会改变方法可行性。

P4四句请求沿贡献者→中介→各模型方→副本返回。P5八句从只能信任进入分享顾虑、保留高价值数据的动机及三服务器定义。三个定义条目分别1/2/1句，Lazy第二句只澄清部分执行；Deceiving长句必须保留同类同量，否则不能说明为什么前两验证不足。P6以两性质、两个问题将道德风险改成可检查对象及成本要求。

P7五句梯度指导训练、敏感性可量化、类别数据量相关、真实移除导致变化、条件限定。这里是经验观察，不是因为梯度随训练变就必然证明删除。P8包含九句分析单元，但不是一个自然段：P8.S1–S8属于从p.2右栏延续到p.3左栏的方案自然段，先比较后门方案，再提出非侵入框架、三粒度、默认精确及近似扩展；P8.S9在p.3左栏独立成段，以三类服务器敏感性签名承上启下，之后才进入Methodology。把两段合为P8只为功能检索，不是源文分段事实。读者先知对手差别，后知信号怎样区分；这种顺序对理解的作用是编辑推断。

P9总领两句，类/量/样本三个方法块4/4/6句。类块比较两模型；量块要先学变化对数量的映射，因此引影子模型；样本块比较目标/测试响应，诚实与同量错删之间作对照。样本块最长，因为需解释为什么总量相同仍可留下不同证据。每块末重复粒度名称帮助索引，却不是必要科学内容；可精简，但不应删逻辑对照。

P10四句回到用户风险、模型副本审计、研究方向及贡献引导。没有独立数值结果段，具体数据集和框架验证在四贡献末两项首次给出。因此不能套用“前面已说方法，贡献越短越好”而删去这些新证据范围。

## 完整贡献及表达选择

C1两句：失信威胁研究与三类型。C2总领句带三嵌套功能片段：类→忽略、量→懒惰、样本→欺骗；它重复P8/P9映射，可作为读者查表，代价是篇幅。若压缩，应保留每粒度的判定对象，而非仅列Metric I/II/III。

C3三句：三数据集、三对象验证有效、脸识别应用可部署。C4两句：SISA和Amnesiac代表两类遗忘框架的外延，及三粒度机制解释。C3是数据任务覆盖，C4是遗忘实现兼容，不能混为同一“泛化”形容词。全篇贡献集合为威胁认识→验证工具→任务验证→实现外延与原理。没有要求每项一个数值，尤其误差单位和准确率不同，更不宜硬凑统一百分比。

## 正文结果池：从一般有效到可选择的证据

类/样本验证平均约90%与数量相对偏差4.8/6.8/8.2%出现在摘要及§IV，不在引言主体。它们可被选入结尾，但类别正确、量估计误差、目标样本辨别是不同成功定义，不能平均成综合质量分。

表V p.12：SISA类验证0.92/0.90/0.89，样本0.85/0.84/0.86，量偏差6.1/9.1/9.6%；近似方案类0.94/0.92/0.88、样本0.90/0.88/0.90、量10.1/10.7/12.1%。这些值支持可应用但不支持所有框架各指标都>90%，且近似数量推断误差更大。近似实验采用随机改标签后更新的具体实现，不能代表所有近似遗忘方法。

§IV多类CIFAR100同时三类各删150，估142、偏差5.3%；§V-C不均衡GTSRB类0.91/量5.8%/样本0.88。这些扩展为条件变化证据，单个不均衡数据集不证明对任意分布独立。

表VI p.13对成员推断：样本验证0.92，比较方法在非过拟合设置0.519、过拟合0.881；该配置耗时8109.92秒对敏感提取52.08秒。选择它可强调非侵入近邻的实证优点，但不可推广全部成员推断算法和相同初始化成本。量验证仍有每影子模型716.79秒训练/55.47秒提取；作者说明可离线复用。类验证约90.83秒、样本每次提取45.33秒且需两次。非侵入与低在线等待时间可以兼得，不等于无训练支出。

§V-E在模型效用降幅≤5%下试扰动/剪枝，敏感度只变3.9/3.7%。这是两种受限修改测试，不是对知道全部指标、可任意训练替代模型的服务器的证明。仅检查提供的副本，不验证服务器所有未交付历史/部署副本。作者明示部分假设，编辑时应把可审计对象说准确，而不是在结尾突然附一堆限制。

## 保义句式对照

原创编辑，不是源句或已证最优。

服务器定义A：A deceiving server unlearns other samples of the same class and quantity while retaining the contributor's requested samples.
B：Although the class and quantity match the request, a deceiving server unlearns different samples and keeps the contributor's target data.
同样保留同类、同量、不同对象和保留目标；A动作顺序清楚，B先强调粗粒度检查可被绕过，适合引出样本级验证。

量验证A：The data provider trains shadow models on incrementally sized target-data subsets and uses their sensitivity changes to estimate the amount unlearned by the server.
B：To estimate the server's unlearned data volume, the data provider calibrates sensitivity changes with shadow models trained on target-data subsets of increasing size.
A先方法过程再目的，B先判定对象再校准；信息一致，不能将估计改精确确定。
