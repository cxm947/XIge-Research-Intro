# FaceArmor：隐私任务、能力条件与作者取舍

## 1. 同一张照片链条中，两个图像对象的好坏相反

【源观察】P1说公开人脸照片可能被操控成伤害名誉或误导他人的内容。图1给分享前加保护扰动的场景，§4开头要求保护扰动不可察觉；P4.S3却主动追求严重纹理崩塌，P5.S4又将视觉伪影列为问题。§4.1明确前者发生于操控输出，§4.2明确后者留在protected image上。

【编辑推断】这不是措辞自相矛盾，而是成功标准有两个对象：用户分享的照片要继续可用，之后被他人再生成的结果要难以忠实重现其结构/语义/身份。旧底稿已提醒表2是生成侧指标；本轮把这个区分向前连接到主语、谓语宾语和局部补语，防止把一句中的degrades误当照片本身的效用目标。

隐私价值因此比“图像质量下降”更具体，也比“公开照片匿名”更窄。源任务针对扩散操控复用，不是证明原公开照片无法被人辨认或被任何识别系统使用。结构失真、文本语义错位、生成身份偏移提供不同证据，不能用一个最大FID替代全部隐私意义。

## 2. 共同表示的理由已存在，新增的是条件与语法的精度

【源观察】P2先承认已有主动扰动，再指出known model组件选择及跨操控路径问题；P3从investigate commonality转向冒号后共同结构/概念依赖，最后提出表示选择。P4按生成任务用途定义两层。§4.1使用代理VAE、ReferenceNet、CLIP和ArcFace，P6明确从surrogate models取得内部信号。

【编辑推断】旧稿已经解释“共同表示→更广迁移”和代理/目标区别，本轮不重复计为新发现。进一步需要处理的是：矩阵investigate/share/maps只是论证骨架，设计依据常在冒号解释、介词宾语、关系从句。读者不知道共同性是什么时，只说architecture-invariant不会完成说明；列四个编码器也不会自动补出共同性。

能力表述应说明未知对象是谁。这里是未来目标生成器及操控范式，不是训练或优化阶段完全无模型信息。代理知识是实现条件，跨目标能力是实验要检验的所得。这样可保留源的强universal/zero-knowledge主张作为作者主张，同时不在转述时把它们升级成不需要任何先验或内部访问。

## 3. 先按功能分层，再共同优化：困难由选择产生

【源观察】P4称两个decoupled tiers；P5紧接联合优化诱发空间冲突，列脸部与背景/衣着梯度的作用区域，指出保护下降与受保护图伪影。§4.2继续说软权重后交叠边界仍有冲突，才引PCGrad。

【编辑推断】按概念分开表征，和优化方向已相互独立是不同主张。新表述若只用decoupled而未解释层级，读者可能以为后段推翻前段；FA06给distinct representation tiers作为有意义的替代，其代价是删去独立性暗示。这里的第二难题不是预先从“有两个创新”倒推出来，而是同一图像扰动需承担多个保护职责。

空间分配与梯度投影也不是一项技术的两种叫法。软信号解决在哪里施加各目标，已有投影处理剩余的方向冲突。方法创新可在结合方式与具体任务适配，引用已有算法不抹去组合贡献，也不授权把整个PCGrad占为己有。

## 4. 保护的实际采用条件决定哪些证据值得提前

【源观察】源引言先报四场景/四模型总体范围，贡献末句另报未知DiT迁移及常见图像处理。§5.1与§5.3说明四任务在SD v1.5/SD XL，SD3/Flux迁移仅inpainting；§5.4报告图像处理后结果。§5.6承认计算时间更高，并将一次性的分享前离线处理作为不必实时运行的理由。

【编辑推断】这里可选的代表性证据取决于读者正在判断什么：

- 担心未来用另一种操控：优先讲跨范式稳定性，并准确交测试范围
- 担心未知生成架构：给DiT inpainting迁移，不把架构数乘任务数
- 担心照片分享经过压缩/缩放：讲所测后处理条件，不能把实测稳健改成任意变换不变
- 担心身份仍被保留：联合看身份相似度及生成质量，而不是只挑失真最大的数
- 担心发布流程是否可负担：用§5.6的离线一次性阶段解释更高成本是否可能被接受，但“可接受”是源作者的应用判断，不是我们替所有用户下决定

计算代价这一取舍在旧profile没有展开。本轮补读§5.5–5.6：消融说明组合职责，成本说明阶段依赖。二者不必都进入引言；当本稿并未主张实时、轻量或移动端使用时，所报告的平均每图处理耗时不必自动抢占主结果。反之，若宣传即拍即发，实际离线成本会改变最早的采用条件，不能只留在限制角落。

## 5. 结果池、解释力度和篇幅的联合选择

【源观察】表2提供多范式/双主模型五类指标；表3提供处理后的均值；表4–5给DiT迁移；表6/图4给组件与优化消融，表7给时间。P7和贡献没有给具体最佳数值，三贡献都两句。

【编辑推断】原引言选择广度与一致性，是为了回答是否跨方法继续保护，而不是单场景打榜。没有数字能容纳复杂结果，但也让效果大小较难直观判断。若要补数，应先确定实际对象与条件，再选能说明任务答案的代表性结果，不能只选FID最高或排名第一；源表格并不每格最优，部分DiT身份相似度仍高，这些事实早已在底稿，不算本轮发现。

强谓语也有职责差别：P3 inevitably、P6 guarantees和P8 neutralizes都是源作者的较强表述；P9 to resolve仍是目的结构，不能与结果谓语混为一谈。忠实分析保原强度，科学资格单列。给新稿的不同变体则明确选择“保证结果”还是“设计意图”，不能把may/is designed to包装成毫无意义变化的润色。

篇幅上，P1四范式长句服务跨领域可理解性；P3方案公告后仍用多句给洞察，是因为映射对象需要理由；P5代价段放在双层之后；P6几句分开信号来源、用途、组合、效果。贡献各两句只是本篇刚好能交产物/实质、策略/机制、评价/边界三组责任，不应把它变成通用条数或等长约束。
