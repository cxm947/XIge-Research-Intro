# SirenAttack：正文证据职责与不可推出的结论

## B1

- locator: §3.1–3.2, PDF p3
- duty: 任务输出/读者模型
- finding: 识别型系统映射原音频到词序列；分类型系统将音频归到给定类别。§4.4 p4以分类可视为单帧特例解释为什么设计按访问权限而非应用分类组织。
- not_proves: 不证明应用×访问的每种组合都被同样评价

## B2

- locator: §4.1–4.2, PDF p3
- duty: 目标与访问假设
- finding: 问题定义同时要求模型改到指定输出、人与原音频相近；白盒有架构和参数等完整信息；黑盒不知道这些内部细节，但oracle给候选类别的置信度。
- not_proves: 黑盒并非只有标签、只有文本或无查询反馈；感知相近为目标而非已被定义证明

## B3

- locator: §4.4, PDF p4–5
- duty: 方法组织的理由
- finding: 白盒采用粗粒度搜索与后续梯度调整的两阶段思路；黑盒不用梯度但仍用置信度信息。末段承认较少信息条件下效率与噪声会受损。这里只记录信息条件和叙述职责，不提供算法运行步骤。
- not_proves: 一个方法名称不意味着各访问条件成本/噪声相同；不能把访问更弱说成无代价

## B4

- locator: §2.2–2.4, PDF p2–3
- duty: 近邻/优先权边界
- finding: 近邻分别有白盒指定转录、可迁移但音素相近、特征重建质量、非定向身份扰乱等不同边界；全篇系统性和首次性均是作者时代定位。
- not_proves: 不能把P3至少一限制改为每个近邻都有全部限制；本轮未逐篇独立复核被引文献

## B5

- locator: §5.2–5.5, PDF p5–7; Table1 p6
- duty: 白盒成功、耗时、扰动分工
- finding: DeepSpeech白盒在Common Voice/VCTK所测样本上报告100%；不加VAD的平均耗时分别1560.14/1897.49秒，SNR18.72/16.54dB；VAD版本分别1201.66/1613.87秒与20.01/18.34dB。
- not_proves: 100%不是全未来输入保证；这些时间不支持所有任务均数秒、实时或5分钟内；SNR不是人类听感测试

## B6

- locator: §6.1.2 p8; §6.3 p8–10; Table4 p9
- duty: 分类成功、成本与失真三种证据
- finding: 说话人被简化为十类；IEMOCAP选1,000片段每说话人100片段，每片九目标。ResNet18行：正常准确率86.37%、攻击成功率99.45%、SNR23.12dB、平均时间386.15秒。各列证据职责不同；该行为分类黑盒直接反馈实验。
- not_proves: 99.45%不是正常识别准确率、云ASR总体率或无噪声率；386.15秒不是查询数或经济费用。1,000片段×九目标是名义组合规模，未公开逐次数据/汇总细节，不能在本轮独立核实成功率分母；也不是9,000个独立人类对象

## B7

- locator: §7.2 p10–11; Table7–8 p10
- duty: 迁移和现实接口
- finding: 500个针对VGG19、由Speech Commands生成的样本被用于六平台迁移测试，未在只回转录的平台直接运行原分类黑盒流程。Table7报告Sphinx39.60%、Google10.00%、Bing14.00%、Houndify12.80%、Wit.ai21.20%、IBM20.40%，作者将这些率描述为定向迁移成功。Table8前七行为作者列出的成功迁移例，后八行为额外误读；前七行亦含目标词与输出词不完全同串的例子，因此具体接受规则未充分交代。原文仅主张一定程度迁移
- not_proves: 不得把99.45%搬到平台；不得将Table8后八行的额外误读直接并入Table7分子；Table7也不能无依据称为严格字符串完全一致率。未证明在端到端服务上直接执行同一搜索成功

## B8

- locator: §5.3 p5; §7.3 p11
- duty: 人类语义保持/察觉度
- finding: SNR作相对失真指标；作者接受部分值低于其提到的20dB门槛并以人评补证。人评200名18–40岁英语母语参与者，每人20原音频+20对抗音频，Speech Commands/CNN条件，安静环境、可重播。93.50%原音频识别正确、92.00%对抗音频按原标签识别，无样本被听为攻击目标标签；38.5%参与者称有一点噪声、10.5%称噪声较明显，只有部分将之归于样本。
- not_proves: 保持词义≠完全听不见噪声，噪声归因于设备≠未察觉；单任务人评不能无条件证明说话人/事件/ASR所有样本的知觉性质；原文叙述在音频识别率和参与者噪声报告之间切换，未给逐试次数据，本分析不推算统一分母或合并为单一不可察觉率

## B9

- locator: §6.3 p10; §7.1 p10; §9 p12
- duty: 多任务边界与外推
- finding: 事件分类另测预先选择的事件对；扰动分析显示成功、时间和感知效用之间有取舍。讨论明确评价假设直接输入音频文件；空中/实时播放、更强迁移及通用扰动为未来工作。
- not_proves: 系统端到端不是物理空中攻击已成立；低平均耗时也不证明实时能力

## B10

- locator: §8 p11–12; Tables9–10
- duty: 防御初评
- finding: 三条路线为对抗训练、下采样、移动平均过滤；表9/10攻击成功率下降但并非零，并有训练可得性、未知攻击泛化和音频质量问题。
- not_proves: 不能写防御已解决问题或保证稳健；C3的潜在/初步阶段必须保留
