# SirenAttack：来源选择与证据边界

## 分析层次

研究理解、任务价值与读者依赖、段落职责、反事实选择、正文证据、词汇作用及贡献集共同支持分析。八条保留子句分析与当前解释分列；已知词类差异由紧邻更正说明。所有选择理由是编辑推断，不推断任何共著者个人执笔。

## 本轮新增的可用判断

1. 对象分类与权限分类交叉但不等同。P1的分类型/识别型解释输出；C1的白盒/黑盒解释可用信息。§4.4主动按权限组织方法；§5与§6实际评价分工不等于所有任务在每种权限都测过。
2. P3三限制是每项近邻至少落入一项的范围表述，不能改成所有近邻共享全部缺陷。P3.S4另开证据充分性轴，不能被前三个方法限制吞并。
3. P4外层比较句是语法主干，冒号后能力分支才负担大部分新信息和话语前景。C2.S2的语法主句是实验结果的报告框架，但有效性宾语才是读者要接受的命题。关系从句/原因从句不自动等于旧背景：P1.S5与P2.S6的重要新解释都在从句中。
4. 成功、耗时、失真、人的判断分别回答不同问题。99.45%来自IEMOCAP/ResNet18十类说话人任务；同一行23.12dB和386.15秒分别回答失真与平均时间，不是成功率的同义反复。正文没有在引言给查询数量或经济价格；不得把时间自动换成这两者。
5. 转录服务和分类置信度服务要分开。§4.2黑盒需要类别置信度；§7.2使用已生成的VGG19样本测试六平台迁移，不是在这些只给转录的接口上直接做同一搜索。C2.S4选择“生成样本”为主语，与该证据关系相容。
6. 人类仍识别原词与人类听不见扰动是不同命题。人评92.00%仍识别原标签，但38.5%称略有噪声，10.5%称有噪声。样本噪声的归因问题也不同于察觉本身。因此P4的低感知影响最多应按所测任务解释；不能由此给完全不可闻保证。
7. 端到端指模型处理/任务链，不证明现实空中传输。§9明确评价直接喂音频文件；空中、实时和通用扰动留作后续。对方法任务价值的解读应保这个边界。
8. P5首次性带知识范围和时代；C3潜在策略+初评是完成的探索，并非未做或完备防御。防御初评见指定PDF §8，物理p11–12。

## 为什么原文如此选择，以及可用替代

- P1先给两类流程再谈风险：让多任务实证成为对象承诺的回收。若稿件只做单一任务，可省去分类框架；若仍宣称跨系统，则不能只留智能助手的泛场景。
- P2把输入时间与规模再接到局部特征扰动：学习的是“特性→任务后果”的说明职责。其图像尺寸泛化和复杂度比较本身不应作为通用事实挪用；今天新稿需本任务证据。
- P3先承认先驱再列剩余：让步不只是礼貌，而是保存近邻正能力。新稿若仅有一个剩余，应直写一个，不复制三个原因。
- P4用长协调句装三能力：适合并列建立评判轴。拆句可以更易读，但不能把每个能力写成无条件已证明；也不能硬造三条一一对应近邻。
- C1以平行访问框架分流：先确定模型信息可见性，再说相应方法。若把两句合一，只保方法名，读者会丢掉何时用哪条路线。
- C2先范围，再有效性，再一数值，再迁移：不同证据不是可互换的排行榜。换成DeepSpeech100%会把前景转到白盒ASR；换成六平台10%–39.6%会突出接口迁移及其难度；换成386.15秒会把主判断转为成本。选择哪项应由当前稿件主张决定，不能将换数值伪装成纯修辞润色。
- C3保潜在与初步：防御的正面价值是识别可研究方向。删这两个限定会把已做探索升级成保证；相反全部改未来式又会抹去真实实验。

## 贡献组的首次信息与回收

C1三句首句回收命名，后两句首次给白/黑盒方法分工与两类目标。C2四句首先把三场景列实，第二句给结论，第三句是有条件例证，第四句另补迁移；并非四句重复“有效”。C3两句第一次引入防御工作与方向。3/4/2只是本篇承担信息量的后果，不能变成新稿配额。

## 学习边界

这是对指定2020版本的论证与语言分析。未实现攻击、生成或播放音频、调用商业接口，未重新验证论文实验，未证明历史首次性，未评价作者人格/个体文风，也未做新稿写作实验。29坐标与完整证据表仅用于可追踪检索，不构成写作增益结论。

## 语法、范围与证据的具体边界

以下限定与 clauses.zh.md 和 evidence.zh.md 的对应分析共同使用。

- 语法词类与逻辑职责分别校正：P1.S2分类依据是句后介词短语；P4.S1是篇章定位；C1.S2是宾语与介词补足成分组成方法组合。P2.S1备选改变主题，不是主动/被动切换。P4.S2三个标签是形容词能力标签；保留分析中的旧词类记录须以紧邻更正为准。
- 替代表述明确保住原有普及强度、每项至少一限制的分配读法、高度有效的评价强度；弱化可以作为编辑决定，但不能称为纯保义变式。
- P4.S2的低感知影响是伴随/对照性的成功约束，不仅是时间同时。不能因句法上从属而把这个要求放到背景。
- 1,000片段×九目标只给名义9,000个片段—目标组合，不能当作已独立重算99.45%的统计分母；原始汇总/筛选细节没有在本文充分公开。本轮不以这种不可重算性断言作者数据错误。
- Table7被作者作为定向迁移率报告；Table8后八行另列误读不能自动进该率分子。其成功例也有非字面同串输出，不能把这个率说成严格字符串一致率。具体接受规则仍未知。
- 99.45%为Table4最高攻击成功率，不是全文最大成功率；白盒Table1有100%。选择哪个值改变证据重心，不能由大小推断作者主观意图。
- 人评词义识别、噪声察觉及归因保持独立；源文聚合描述没有足够逐试次数据支持统一分母重算。20dB只记录作者引用及其讨论，并未验证为普遍听觉阈值。
