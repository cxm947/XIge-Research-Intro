# DEEPSEC：完整引言子句账本

源身份与公共PDF见 `source-coordinates.json`。沿用完整图的P1–P4、C1–C3和END-S1，共35个分析单元；默认单元路由登记其中34个P/C/R单元，END-S1是图内可读而未登记路由的终结导航；P3.R1–R4为列表单元，C3.S1a/b/c是同一句的三个发现子单元。下列`.a/.b`只在本账本中区分子句或承担论证职责的短语，不另造可供原路由读取的源坐标。词数为整句或整个列表条目，不把分句再计一次。C3共同主句另列为本地补充，未冒充原图缺失的正式坐标。

**标记。** 每行“可见结构/内容”是源观察；“关系、取舍”是编辑解释；“迁移操作”是条件性建议。中文为分析性释义，不是逐字翻译。句法式中的主/从/修饰是结构关系，不是可直接填词的写作模板。

## 6. 跨句与删改依赖复核

- **P1.S4→P2.S4→P3.R3→C1.S2→C3.S1a：** 任务双目标、单指标不足、指标需求、平台区别与关系发现形成一条选材链。链条教的是哪些信息必须共同出现，不是五处照抄同一句
- **P2.S5–S6→P3.R2→C2.S2→C3.S1b：** 对手选择捷径受挑战后，覆盖才有价值。需要真实威胁对象和比较协议；否则完整矩阵也不能保证回答同一问题
- **P2.S7–S8→P3.R4→§III：** 动态认识给扩展性理由；扩展接口可作为资源价值，不能变成未来有效性的结果承诺
- **P2.S10–S12→P3.R1：** 历时条件变化说明需要能解释结果差异。它既可支持统一比较，也提醒统一条件会改变所回答的问题，不能只从“统一”推出“公平”
- **P4.S3→C2→C3：** 可以做什么、实际做了什么、因此知道什么各有职责。去重应该移除重复事实，不应把这三个层次压成仅有实现介绍
- **C3.S1c→§V-B/Table IX：** 句法对称不证明两半命题都成立；选证必须分别核查整体比较和所谓下界

这些联结是在整篇阅读后作出的编辑解释。逐行齐全只证明本账本覆盖了原图单元，不证明每个句式都值得仿写，也不证明源研究结论正确。
