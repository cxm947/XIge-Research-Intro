# PRSA：从子句作用域到作者取舍的追加剖面（审后阅读版）

## 本次真正新增的判断

两种任务能力能在 P5 中并列，却不能把 P7 写成并列模块清单：前者需要分别建立判据，后者需要解释第一步完成后为何还不能交付。这里的句法价值不在于用了某个连接词，而在于读者此时容易把“意图推得更准”误认为“可换输入使用”。P7.S5 关闭这种错误推断，随后才有理由引入另一种选择依据。

以下所有“为什么这样更合适、换写会怎样”的判断均为编辑推断，不是作者对自己写作动机的陈述。论文中的实验、第三方确认与新颖性均按作者报告处理。

[指定主源](https://nesa.zju.edu.cn/download/usenixsecurity25-yang-yong.pdf)。完整引言在物理 2–4 页。正文仅定向回查，并未逐句重读全论文。本文件保留分析坐标；精确原文与版面回查指定主源。

需要显式记录的版面关系：

## 2. P2 → P5：先让能力要求有对象，再让困难有根因

### P2.S1–3：关系从句与对照从句先安放条件

P2.S1 的两个服务名不是自足分类。挂在各名称后的关系分句把互动条件安放到相应对象上，读者以后判断某种攻击能否适用时可以回取，不必在 P3、P4 才临时接受新限制。若把两个关系分句另起为两个主句，注意力会变成服务对比；在研究对象本身陌生、读者尚不能区分两者时，这种拆分有价值。但当前段落还要走向共同要求，原组织让分类承担定位职责，避免对比吞没主线。

P2.S2 的主句先宣布两个共同特点，冒号后的第一项再交代商业展示形式；目的成分解释展示为什么存在，付费前的时间边界限制这次可见信息。不能把目的成分读为攻击者目的，也不能把有限试用和单一展示理解成每个平台同时提供两者。被动商业化表述没有凸显服务运营者，重心留在攻击者可观察的对象；改成运营者作主语，会更适合写平台激励或治理，但不会凭空增强本研究的信息前提。

P2.S3 里的 while 是两种资产载体的对应关系，不是时间，也不是优劣。S4 再用共同指称收束，使读者把差异与共有性质分开。这一步若省去，后文泛化要求容易显得只属于模板，而不属于应用中的系统提示。

### P2.S4–5：能力主句先立不变量，例子再变自变量

S4 主句的意向性表达描述服务设计要求；后接的结果性非限定成分不能独立证明所有服务已经实现无条件泛化。S5 把接收变化输入和产生相应输出保持同一施事。读者因此能同时保留“可变内容”与“稳定功能”两层，而不是把例子里的具体产品记成研究目标。

如果当前稿件正在定义严格判据，可把该关系改写为“评估应固定任务功能、改变用户输入”。这样前景化的是实验要求，适合方法或评估设置；在本段就采用它，则会过早由市场现象跳到作者的评估动作。两种写法各有用途，不是长短或主动被动的等级差。

### P5.S2–5：两个 how 结构共享任务，却不共享失败原因

S2 的疑问补语指定要获得的能力，少量观测是附着于推断动作的输入条件；不能把“少量”移给输出数量或整个训练来源。§3 与 §5.1 还说明存在类别信息和辅助公开材料，所以“一对”约束的是目标服务的观察，不能改述为完全没有辅助知识。

S3 的因果解释回指上一挑战，困难对象是详细意图。将原因放在能力要求之后，先让读者知道“要做到什么”，再回答“为什么现有条件不够”。如果读者已经接受任务、争议集中在瓶颈是否真实，可把原因前置；此时是在改变论证入口，不是在靠 because 制造更强因果。

S4 的疑问补语换了交付判据；给定观测仍是来源条件。S5 的原因从句先提醒输出混合了两类来源，主句才聚焦推断时的误纳风险，末端时间从句限定错误发生在哪个操作阶段。这里隐含的动作施事是执行反推的模型/方法，不能误配成用户把内容误填进服务。它不是“输出质量差所以泛化差”的空泛链。

一种适合诊断段的保义换写是：先以反推方法为主语指出来源混淆，再把输出的混合性放到后置原因中。它把责任机制提前，适合回答“谁在哪一步混淆了什么”。原顺序更适合此处：读者刚接受第二个能力要求，先回到共同观测物，再获得误纳机制，两个挑战因而共享对象而保持根因不同。

## 3. P6 → P7：从总能力到可检验的两个设计选择

P6 是承诺层，不是证明层。S3 把生成模型的用途嵌在洞察中，S4 再以功能能力收束；末端关系分句限制所要生成的对象。若只抽取 P6 来教“机制应含某个模块”，会忽略 P7 才承担机制可信性的工作。

### P7.S1–4：观察、可用性推断与实现，不能相互顶替

S1 前置目的收回 P5.S2 的任务约束，主句再给思路来源；它没有声称借用一个术语就足以解决问题。S2 的宾语从句陈述观察，其中非限定谓语修饰“因素”，类别范围限定因素相似性所针对的推断对象。句尾相似性才是可供下一句使用的新判断；不应把整句压成“同类提示相似”，那会把需要学习的差异因素偷换成提示文本相似。

S3 的方式成分先回取这些因素，主句给模型在既定类别范围内的能力后果。能力情态并不是逻辑充分性证明。S4 随后把研究者放回主语位：依据前述洞察作出算法选择，输出差异是操作依据，识别因素是目的。三个句子的认识地位不同：观察→利用观察的能力推断→研究设计。仅保存谓词类别会失去这条证据梯度。

§4.1 对类别分布和离群点的讨论，使这里值得保留的是“可利用的规律”，而不是“类别之间有严格不重叠边界”。若新稿已有很强的定理保证，可以把条件与推论改为正式蕴含；这篇的实验性观察不支持那种换写。

### P7.S5：残余句到底回收什么

P7.S5 的命题释义：但由于第二个挑战，上一步仍不足以完成整个任务。

这里 this 的最邻近可用先行内容是刚解释的生成阶段及其意图推断改善，不宜只指最后一个名词或某个因素。原因成分唤回 P5.S4–5，作用域是“尚不足以完成整个任务”的判断。它既没有撤销第一阶段的贡献，也没有声称第二挑战由第一阶段新制造。

删除此句，读者可能更容易把前文承诺的功能复现理解为已经足够；P5 与后续句仍提供纠正线索，但这个局部交接不再主动防止误读。随后修剪可能被看成任选后处理、一般清洗，或同一目标的冗余优化。把它仅换成“此外，我们还……”又会丢掉不可替代性。一个有用的替代应把未闭合的判据写到主位，例如：即使意图推断得到改善，交付物仍可能把示例输入当作固定要求。这个编辑改写更显式，适合两种判据相隔更远、读者回忆负担更高的新稿；本篇距离较近，原短回指可保持推进速度。不是通用地越解释越好。

### P7.S6–8：从选择依据到策略，再到任务闭合

S6 的目的成分回接未解事项；核心系词结构给新的选择原则，而关系从句限制要处理哪类内容。语义接近是启发式筛选线索，不等同于已经识别“应删的一切”。S7 的依据成分指向这条新直觉，不能错接到第一阶段的类别相似性。两次相同的连接骨架在此有不同先行命题。

S8 以策略为主语承接 S7，把手段、筛选目的与最终泛化结果串起来。正文 §4.4 明说过量过滤会损害功能，故搜索不是为“更多删除”而存在，而是为兼顾另一判据。这个约束补强了原有双阶段解释：要排除的是输入特定性，不是所有与输入语义接近的任务内容。句末结果成分是作者的设计解释，不能从语法强度升级成所有输入上都可靠的数学保证。

如果新稿的读者最担心误删，应以保留任务逻辑的选择约束为主句，再从属地交代筛选方法；如果先要理解整体流程，像原文这样以策略为主语更顺。替换应响应当下疑问，不应强制把所有机制句改成主动 We 句。

## 4. P3.S9 → P8.S4：同一个成本命题，前后承担不同举证义务

P3.S9 前置比较框架使“低”有参照；主语是执行成本，不能读成资产价值低。它目前只帮助说明为什么值得研究。P8.S4 把同一经济问题作为独立主句重新拿出，前一成功率回答“做得到吗”，这一句回答“有没有低价替代购买的激励”。这正是值得单独成句而不塞进成功率括号的理由。

新补的分母约束来自 §6.4 与 Appendix E：引言区间基于成功攻击单位的平均成本，再与相应提示均价比较；跨两种模型及自有/云计算成本口径。不能解释为每次尝试的价格，也不能把最高/最低端点当成同一单个设置的波动范围。其句法关联是：引言表层的所有格/介词关系比正文定义更短，复用这一句时必须随预期读者补回分母，而不是借简洁省掉含义。

有两种有用改写方向：给安全读者，以成功攻击的单位经济性为句首；给运营决策者，以替代购买的成本差为句首。只有当前任务真在回答计算开销，才该改用 token 或时间作为主焦点。本篇经济证据回应 P1 的资产价值与 P3 的低成本动机，故单用速度替换它会改变问题。

数值核查新增一处保留项：表 5 的 GPT-4 数值 46.1 与 17.8 给出约 159.0% 的相对提升；引言用超过 160% 的表述。原读图没有错抄引言，但新成文若要精确陈述，应使用表中起止值或约 159%，不能把原近似表述当作精确算术结论。这里不替作者猜测舍入、计算或编辑原因。

## 5. P8：限定成分控制外推，主句承担读者要记住的答案

S1 先给两个场景，S2 与 S7 分别建立相应结果的解释域。它们不是可以压成一个总体分母的两次抽样；同样的场景前置形式帮助读者换域。S2 中来源、类别与选择方式各管不同对象：来源限定取样出处，类别描述覆盖，随机选择不能被改写成覆盖全部商业服务。

S3 以 evaluation 为证据框架，能力结果进入宾语从句，相对比较依附于该结果。替换成相对提升作主句会前景化比较增益，却降低读者对绝对成功程度的感知。旧反事实已经指出这一点；新增的判断是：若当前写作目标是比较优化幅度，这种替换可以成立，但须保留模型与基线口径，不能把数值最大化作为唯一选材准则。

S5 换到生成物作主语，避免评价只剩二元成功；S6 又换回作者动作，加入另一种检验来源。它们分别回答交付物性质和证据可信性，重复 We 不是唯一连贯方式。将二者合为“验证效果良好”会抹去这种分工。

S7 的全称关系从句只量化当前样本，不能外推为整个商店全部有防护。§5.1 的样本描述与 §7.1 的开发者联系说明这是报告中的选择与确认背景；其防护内部机制仍未披露，作者给出的成因解释含推测。S8 的结果依赖这个已建场景，但并不证明所有防护机制都被突破。

S9 把应用的知名度历史放入非限定关系分句，主句的发现保持焦点；末端限制性关系分句则区分新发现与已公开描述，并交代引证方。若删掉知名度插入语，核心发现仍成立，只减少现实暴露感；若删掉未公开与确认限定，证据会更像输出复现展示。这两种删减的损失不同。引言把确认语附于发现，§7.2 的叙述则明确报告所得提示被开发者确认；本次未独立联系开发者，不把两处转述扩写成第三方对全部功能的独立认证。

S10 是上述异质证据的归纳，不是新增实验。C2 后来之所以可以压缩，靠的是这里已经把覆盖、绝对效果、经济性和可核对功能细节各自放到合理位置。只学习它最后的概括句，会得到空泛贡献。

## 6. P9 → C1–4：解释不是保证，贡献压缩不能压掉辨识条件

P9.S1 的分析动作与相关性观察同句出现，不能把相关改写成因果机制已被证明。S2 的依据成分把观察转为候选防御，潜在性修饰的是防御状态。S3 内层让步承认防御效果，主命题却要求权衡；若将后者从属、前者独立前景化，会把读者重点由可用性代价改为防御成绩。S4 把另一方案的不足留在主位，再推出待改进方向。这里不是为了句式多样化而正反各来一句，而是两种结果需要不同模态。

C1 的主句声明框架，包含结构把关键算法纳入方法贡献，关系分句说明由它支持的能力，末端单目标样本让步把能力放回现实约束。此条件即使在贡献中显得重复，也有辨识作用：删除它会削弱与依赖较多目标输出的近邻之间的区分，但算法身份和现实场景并不会随之消失。相反，P8 已报告并展开的若干规模和数值可以不逐项重列，因为不重列它们不改变贡献对象。不要把这种区别教成“数字一律删、条件一律留”；应问删后能否仍区分最强邻近答案。

C1 还作了一次更具体的压缩：它点名 attention，却未重新枚举 pruning。可解释为，P6 已定义整个框架，P7 已使第二阶段的必要性可理解，因此框架名能够回收整体方案，贡献项只显式突出 attention 算法与少目标样本条件。这是编辑推断；不能据未点名就说 pruning 可有可无、没有独立新颖性，或作者已自述这一写作理由。

C2.S1 把实践评价作为主动作，风险判断作为其结果，伦理副词不能替代伦理程序证据；S2 提供可检查的另一个产物状态。C3 以分析为主动作，未来防御认识是用途，不能改成已经部署防御。C4 则并列报告与合作行动，目的成分说明合作指向；目的不能变成完成状态。与 §9.1 的尚在探索相连，贡献结尾保留真实行动，比强行追加一项新算法更忠于全文。

这些贡献不是固定四格模板。压缩依据是“此前哪些判断已经交代、此处哪些条件仍决定身份”，不是篇幅、句数或关键词配额。

## 7. 已保留、被收紧与仍未知

- 分析关系：两种信息障碍、残余交接、经济证据、异质结果职责、短贡献对长结果段的依赖
- 收紧：单样本属于目标服务观察；P7 残余不是新生副作用；相似性筛选不许可无差别删除；成本区间需跟成功单位及成本口径；全称只管样本；作者报告不等于独立复现
- 新发现但不越界修补：引言相对增益与表 5 的精确算术有差异；§5.4 的语义指标叙述与公式后列举也出现名称不一致。本篇只据这些限制复用表达，没有判定实验实现是哪一种，亦未做完整可复现性审计
- 仍未知：作者真实写作动机、extended 版本相关证明与阈值选择细节、本次未读引用报告的独立有效性。例子的作用解释均是编辑推断
- 本文分析不证明对新稿的写作收益。
