# 向作者固定框架迁移的路由，非源文结构复述

唯一源版本：MOPT19，[USENIX Security 2019正式PDF](https://www.usenix.org/system/files/sec19-lyu.pdf)，source_id sj-d51010872e；具体句页与现有reader坐标见[分析中的M01–M15](analysis.zh.md)，应用改写见[句群G01–G12](sentence-groups.zh.md)。下列“P”均指作者目标稿位置；`src.P`才是源论文实际段句。源文12正文段和五个问题因素没有被追认成作者五段。

## P1 背景→任务

可用M01/G01：从同一软件测试活动收窄到变异式fuzzing和漏洞发现。研究局部对象是mutation scheduling，P1的任务终点不因此降格为“优化PSO”。源文直接进入任务只说明它怎样有效命名任务，不授权删除作者已定大背景与小背景。

## P2 桥接现有流程和实际要求

可用M02/G02：已有算子定义操作，调度输出分布，fuzzer据此变异并执行输入；必要时补havoc与确定性阶段。这里先给P3/P4成立所需关系，不把源src.P2开头的gap转折强行带到作者P2。

## P3 挑战一及其剩余

候选职责：在算子收益随目标及运行状态变化时，把有限测试机会分配给当前更有产出的操作。

可用M03–M05/G03：先交机会错配这一任务损失；再给有据的算子/程序/时间差异；极简保留均匀固定分配与已能动态选算子的RL路线；最后指出动态变化本身还不是任务收益的答案。Fig.3只能支持其实际测量对象，不写成每调用成功概率或因果贡献的精确实测。

## P4 挑战二及其剩余

候选职责：让运行时适应在稀疏反馈与实际fuzz循环预算内及时产生净发现收益。

可用M06/M10、G04/G07：高频决策计算占用测试预算，有效反馈稀少；AFL系还有长期困在确定性阶段、havoc更新机会受限的问题。极简已有办法可以对应常规阶段流程和源文讨论的学习式调度，然后说明当前真实反馈/预算条件下仍缺什么。

独立性判断：P3问分给谁，P4问怎样使调整及时变成可用测试机会。若目标研究没有足够证据支撑第二关系，不因作者框架需要两段就制造它。该两分法是编辑迁移，不是宣称MOpt作者先写了两个挑战。

## P5 策略回应

可用M07–M10、G05–G07：先交一个准确整体交付和任务；再说明观察到的有趣输入产出如何驱动选择分布、多候选比较与后续利用；若是AFL系，阶段控制使更多种子与分布更新获得机会。反馈代理与真实漏洞发现的层次清楚，但不在方案段堆砌全部评价定义。

机制可以同时回应两项挑战，不要求一个挑战对应一个模块。PSO名、pilot/core名、pacemaker名只有能解释选择时才保留；模块数量不决定贡献数量。

## 紧接贡献，末项评价

可用M11–M15、G08–G12：按实际所得归组为诊断/设计原则、调度能力及关键策略、必要实际产物或资源、实验与主要结论。具体取3–4项取决于目标研究实质；本分析不机械要求MOpt原有四项全部照搬。

源原文C3是评价，C4是发现/资源；作者要求末项评价时可重组，不改作者框架。P5和贡献保留必要呼应：前者讲选择为什么有效，后者确认已得到什么。评价以同配置、同预算的任务结果为主；研究期间tmp与ever两配置的发现并集为112个漏洞是独立安全产物口径，不挤进单配置相对增幅。

## 正向价值的保留顺序

1. 用户真正要完成的漏洞发现任务
2. 分配策略能改变的测试机会及其反馈依据
3. 为什么改变会在实际时间预算内起作用
4. 同一配置下得到的任务产物
5. 证明上述能力如何使用的必要条件、代价与支持性指标

此顺序是取材判断，不是新增加到作者引言的五个段落，也不是必须套用的句数或数字配额。

## 按当前决定使用的三个例子

- 需要写短的评价末项，前文承诺是同预算漏洞发现：选M12–M13/G09的tmp整组，以13程序、每项240小时、88对33漏洞为主。若当前要确认实际安全产物，则改选G10的tmp与ever并集112、其中97此前未知及其中66新CVE；两个用途可以分句共存，不让并集继承单配置增幅。
- 需要解释为什么不以执行吞吐领衔：选M14/G11的mp3gain、tmp对AFL同一例子，保留182.2M→117.2M执行与6→12漏洞。它帮助区分成本指标和任务产物；若问题变成纯调度函数开销，则这张全系统表不足以回答，需另有隔离测量。
- 需要为P5选择必要机制：先用M07/G05交反馈如何改分布。若宿主是AFL系且阶段停滞确是任务阻力，再选M10/G07的pacemaker；若是VUzzer，选M15/G12的宿主fitness反馈条件，不继承AFL的新路径/崩溃代理或确定性阶段控制。
