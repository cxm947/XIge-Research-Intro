# AdversaFlow：段落依赖与贡献证据职责

- organization_unit: 源P6后有贡献引导句，旧坐标未独立编号；不将其遗漏说成科学分析缺失。
- edges:
  - 
    - from: 人工有效但难规模化
    - to: 自动生成探索
    - role: 缓解规模而非宣告问题全解
  - 
    - from: 反馈质量条件+双模型可能偏离
    - to: 专家监控/诊断/调整
    - role: 人的判断职责
  - 
    - from: 总体趋势与具体失败需联接
    - to: 多层流及正文实例联动
    - role: 粒度对应可完成动作
  - 
    - from: 跨检查点不稳定+上下文传播
    - to: 分布线索与波动路径
    - role: 观察现象/计算信息/可读表达共同支撑诊断
  - 
    - from: 三项贡献
    - to: 案例过程、反馈、独立数据结果及经验
    - role: 不同证据职责，不以赞誉或单个ASR替全部
- epistemic_note: 源句顺序、语法、粗体和数字位置可观察；它们帮助读者判断何事是编辑推断。
