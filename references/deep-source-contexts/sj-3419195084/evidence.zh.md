## 2. 可以支撑主线的设计证据

### D1：真实共享与学习流程

§III-A和Figure 2：各方底模产出表示，归一化后二值化，服务器拼接代码进行分类并计算类别目标码距离；反向通过STE近似传递梯度。§III-C具体区分前向Sign与反向梯度估计。

可用：设计使二值共享和继续训练在不同计算方向上得到安排。

不必在引言展开：全部变量、张量形状、优化器、逐行算法。

不支持：仅凭可传梯度就保证所有数据上效用不降。

### D2：公共类别目标是多职责关系

§III-D明确类别码既用于降低一致性比较成本，也用于分类；§III-E给出二值代码上的汉明距离与余弦目标关系。P8给出比较次数从O(N²)到O(N)，N是参与方数。

可用：同一共享参照组织跨方语义、指导优化，并降低一致性约束中的比较数量。

不支持：整个训练算法复杂度变成线性；同等幅度的通信压缩；经过实测的大规模时延改进。本文对应位置没有提供这些量。

### D3：有限码预算是实际实验条件

§V-A把每方码长设为ceil(log2 C)，C为类别数。二分类使用1位，MNIST/CIFAR10使用4位，FER按7类使用3位。§VI-B另研究4至128位，不与Table II混为一组。

可用：极短表示下能否支持分类，是论文实际评估的问题。

不支持：越短必然对任意隐私定义越安全；最短表示总有可接受性能；公开特征切分数据等同真实机构联合部署。

## 3. Table II：代表效用结果（第6页）

列顺序为无防护准确率、HashVFL准确率、HashVFL减无防护，单位均为百分比／百分点：

- MNIST：98.99，97.75，−1.24
- CIFAR10：76.22，70.83，−5.39
- FER：55.93，51.11，−4.82
- CBPD：50.30，69.34，+19.04
- CRITEO：70.72，72.94，+2.22
- IMDb：73.64，69.72，−3.92

六个数据集覆盖三个图像、两个表格、一个文本数据集。§IV以公开数据特征切分模拟VFL，主要采用两方设置，图像底模ResNet、文本BERT、表格MLP，顶模为MLP；不是六种生产VFL系统的部署测量。

比较对象写作“文中无防护配置”最稳妥。§V-A明确解释二分类时嵌入长度也设为1，使无防护服务器仅收到两项浮点输入。这解释了为何CBPD的19.04个百分点提升不宜作为“哈希通常提升学习能力”的代表数字。论文未在这个表中给出与充分调参、大宽度、其他防御的统一竞争比较。不要凭此扩大为优于现有VFL防御。

四个下降值中最大为5.39个百分点，而不是相对下降5.39%。若算CIFAR10相对变化，5.39/76.22约为7.07%，但引言无需另加这个比例。这只是表中已观察值的概括，不是理论上界；只属于此表，不覆盖后面的CIFAR100或任意参与方设置。成稿写“约5.4个百分点”同样合理，保留5.39是沿用原表两位小数，不能据此声称测量精确到该位。正常约数与舍入不应自动当作夸大错误。

采用理由：即使共享表示被压到仅按类别数配置的位数，仍保留可用的分类表现；读者可以同时看到具体效用代价。数字的任务对象和预算比“效果显著”更能支持采用判断。

## 4. Figure 3与Table IV：主重建证据（第7–8页）

§II-D威胁模型设为诚实但好奇，对手知道其他方底模及样本哈希代码，不知道其本地原始数据。§V-B实际共同特征恢复优化使用目标类别的预设二进制码，尝试令生成输入的底模输出接近该码，并加TV项；这是该文的经验攻击设置，不等同所有可利用先验的攻击集合。

Figure 3：对各类别码进行3,000轮重建，展示MNIST的4、8、16位结果。视觉上是噪声状图，缺乏可辨识的数字轮廓。它回答“该攻击能否从类别共有代码提取直观共同特征”，不能当成逐个私有样本唯一恢复的不可能性证明。

Table IV的均值及标准差：

- MNIST：SSIM 0.0157±0.0137；KLD 11.5757±7.2420；DCOR 0.8757±0.0487
- CIFAR10：SSIM 0.0620±0.0366；KLD 340.5571±270.2468；DCOR 0.8540±0.0916
- FER：SSIM 0.0948±0.0511；KLD 813.7469±536.4684；DCOR 0.9004±0.0693

可用：在所报告重建统计中，三个图像集的SSIM均值很低；低结构相似度与Figure 3支持该类经验防护结果。若引用范围，说明它是三个数据集均值的范围0.0157–0.0948，不是置信界或最大单样本值。

需保留的判断：Table IV没有把每项统计的完整代码长度和采样细节展开到可与Table II逐格配对，不能把两个表拼成一个统一数值承诺。其DCOR列数值较高，与紧随正文把各指标统合为同一趋势的解释有张力；因此本分析不借“三个指标一致”提升结论强度，也不把SSIM解释成绝对零信息泄漏。主文只需采用有支持的经验重建结论，详细指标差异留本附录。

## 5. 机制消融属于哪种证据

Table X（12页）对比Greedy Hash及HashVFL加／不加BN。二方、各持一半特征、4/8/16位。CRITEO4位由不加BN的49.76%到加BN的73.70%，足以作为“该组件在这个配置影响实际分类”的局部实例。

不应泛化：原文文字说在所有数据集优于Greedy Hash，但IMDb4位是HashVFL68.59%对Greedy Hash70.71%。因此若写跨配置结论，不能说18个格子全胜。该例不削弱“解释短码利用为何值得处理”，它只改变比较范围。

§VII-B与Figure 6比较有／无一致性目标的训练曲线，讨论早期训练较快及后期过拟合迹象。可说明共同类别目标除比较成本外还被用于学习；不能推出所有时期、所有码长收敛都更快或最终准确率总更高。

## 6. 不作为本篇主贡献代表数字的结果

- Table III的标签推断使用默认16位码；MNIST攻击准确率95.05%降至85.24%，仍有较多标签信息，CBPD甚至从62.41升到63.17。它是额外隐私任务，不能代替防输入重建的结论
- Table V中的某些PGD攻击成功率为0，属于特定阈值、步长和16位配置；CIFAR10有一格反而从66到85。零值更醒目，却不回答短码能否同时维持协同分类与防重建
- Table VI的异常输入检测利用跨方代码差异，并有类别例外；属于一致性关系的衍生使用，不必重新写成主应用挑战
- Table IX显示CIFAR1008位时无防护33.99%、有防护24.23%，下降9.76个百分点；32位为34.75%和33.31%，下降1.44个百分点；64位为33.39%和33.77%，上升0.38个百分点。它可用于适用关系，不支持把Table II的最大观察降幅5.39个百分点外推到所有分类任务

## 7. 两项技术用语的正向校准

### 7.1 多对一的信息损失与普遍安全保证

Sign丢弃幅值，有限码长会有碰撞。这些是值得明确写出的表示性质：仅由代码不能一般性地唯一确定原来的连续表示。这种设计性质可解释为什么它被选来减少共享信息。

但从非单射不能直接推出利用数据先验、关联信息或目标限制的所有攻击都无法近似恢复，也不能推出不泄漏类别或群体特征。原文自己继续研究标签与共同特征，说明所保留的任务相关信息也有隐私含义。迁移时将“采用方向／表示性质”与“具体威胁模型下的经验结果”分句，就能保持正向价值而避免无依据普遍化。

### 7.2 归一化、位均衡与任务信息

原文P7及§III-B把BN的标准化与正态分布、正负均衡相连。数学上仅均值为0和方差标准化不保证正负样本数相等：例如−3、1、1、1的均值为0，标准化仍是一负三正；带可学习平移时更不能据此保证符号均衡。这个反例只是阅读中的逻辑核对，不是数值实验。

因此正向可写：在极短码预算下，作者用BN处理各维的分布和位利用，并以消融检验分类效用。若要说严格每位均衡或联合信息最优，需额外证明或测量。本分析保留“有限预算→利用每位→选择操作”的因果写作经验，不传递未经支持的技术保证。

## 8. 贡献中需要保留与可以省掉的条件

必须保留：首次结果中影响判断的短码预算；相对于何种配置；安全结论是所测重建结果；不同评估组不能伪装同一联合试验。

若前文已交清，可省掉：VFL的全定义；银行与电商例子；STE全称与公式；每一数据集名；全部超参数；三个设计要求再解释一遍。

只有要声称对应能力才需要：大规模部署效率的实测；形式化安全保证；标签泄漏／PGD／异常检测结果；生产可用性或用户易用性证据。不是为了显得稳妥而在每个末贡献后追加这些限制清单，而是根据实际主张决定是否需要它们。
