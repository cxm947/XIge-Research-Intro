## 2. 研究理解：四层未满足要求，不能并成一句“现有方法不好”

第一层是保证类型：防御曾提供经验上的缓解，但可被更强攻击绕过，作者因而把问题移到可认证的邻域保证。认证不是保证任意输入、任意范数或任意扰动，也不是仅有较高测试准确率。

第二层是跨特征分配：uniform以共同尺度处理不同特征；non-uniform已允许不同特征有不同半宽。后者是真正更强的近邻，不能让新工作的价值建立在忽略它的基础上。

第三层是同特征方向：即使每个特征已有自己的尺度，正负方向仍被等距要求绑定。新定义释放的是同一特征的左右自由度；这与跨特征差异正交，不是把“异质性”换个形容词。Problem1的两个退化关系回证这条层级：左右向量相同可退为non-uniform，再让所有坐标共用标量可退为uniform。此为表达空间的包含关系；并不自动证明任一近似求解器的每次输出都严格支配其他算法。

第四层是使新对象成为可用任务：方向自由度值得保留后，P5要求能够认证的形式化和多架构有效计算。这里的应用意义是为实际模型提供可用的安全区域信息，不是凭空加一个自动驾驶实时计算约束。作者指出既有FCNN接口对其他结构采用稀疏全连接表示，为原生架构约束提供理由；不能改说此前完全不能认证CNN。

随后才出现第五个、性质不同的困难：M1给出更自由的新优化后，M2说明这个具体形式化直接求解昂贵。它是新设计引出的计算代价。源文虽早已要求高效认证，却没有在设计前预知这一特定优化对象；把M2.S1前移成原始“应用挑战”会使指代无对象、推理顺序倒置。M2/M3是完成新任务所需的处理链，并不是三个不相关工具名的并列广告。

## 3. 价值与读者前提在同一次选材中发生

本源最可迁移的选择不是“先讲大背景”，而是用不同粒度的材料补不同缺失关系。

1. 安全后果例子补“为何需要保证”，没有被冒充本文已测场景
2. uniform到non-uniform的承认补“强已有答案已做到哪一步”，使新工作不重复其跨特征贡献
3. 同模型、同输入的一维例补“仅松开方向约束会多知道什么”。旧区间受近侧阈值绑定，新区间利用远侧安全余量；价值是更充分描述固定模型的已有安全空间
4. 分号并列的变量与架构接口补“怎样表达新对象且保网络结构”；两个理由可共同贡献于形式化，但没有“独立变量自动带来CNN支持”的因果
5. M2的短代价句补“为什么形式化之后还需要一步”；逐层界、整体界、约束、求解产物按依赖交接
6. 两项应用补“方向信息除了让认证数字变大，还改变什么研究判断”：威胁分析要联合看成功和扰动，解释用途依赖正负方向差。应用不是可任意替换的场景清单

以上选择理由是编辑推断，建立在实际顺序与证据职责上，不归因于某位共著者的个人写作意图，也不声称已实验测量读者认知负担。

## 4. 句法主命题不等于话语重点：本源有六种清楚分工

完整逐单元分析见 clauses.zh.md。这里记录跨句取舍，避免只贴语法标签。

- P1.S1的矩阵脆弱性既是语法主断言又是下一段的议题；但其从属定义仍是陌生读者不可缺的新信息
- P3.S1矩阵报告研究转向，真正改变任务理解的是关系从句中的保证内容。删去从句虽然留下主谓宾，却只留下术语
- P3.S4目的前置承认近邻发展缘由；矩阵交提出者和概念。目的位置不能让跨特征能力被当作次要装饰
- P3.S5的while部分是非限定分词结构，并非另一个完整有限从句；结果分词把共同行为接到界的损失。迁移时要保“两个近邻共同假设→遗漏另一个轴→量化损失”的关系
- M1有两个并列有限分句，每个后接产物说明；M2.S3矩阵得到整体输出界，尾部关系从句说这些界怎样进入优化。方法产物的去向虽语法从属，却是解释闭环的必要部分
- P7.S2/C2.S2/C3.S2的矩阵都是证据报告框，研究主张在补语内部。不能机械地把we show当主要信息，也不能因为结论在从句就缩小其证据义务

C3.S4尤其需要分开看：表面现在时结果句强断言，前句将它置于未来研究方向，正文只给示例推理和可能性。语法事实、篇章角色、已获证据三者并不完全同强度。新写作应修这一张力，不能为替源文辩护而说它的句法本来就带情态。

## 5. 理论、实测与用途各自证明什么

### 5.1 理论/分析材料的恰当职责

Problem1表达方向变量、架构递推和类别间隔约束；特例关系支持新旧定义的比较轴。Theorem1及后续处理给层界传播依据：输入已有上下界，线性/卷积运算按权重符号组合；正文借单调激活及池化继续得到输出界。这里核对的是声明、条件和论证接口，没有完成独立证明审计。

Problem2对真实网络约束采用保守的输出间隔充分条件，再以非负松弛量表为等式。原文自己说明是可靠但不完备的解。不能仅凭引言的“relaxation”把它理解为可行域一定扩大，不能说任意不等式直接换成等式而等价，也不能把最小化目标上的上界混称认证安全空间的外包络。为了训练/评估写作，可分别说：其结果用于认证域内安全；最大真实安全区域可能仍有未捕获部分。

M3采用定制求解并在算法后部收缩界至满足约束。这里未核对收敛性或全局最优；“高效”与“求得最佳真实边界”是不同主张。源文对计算复杂性的说法是引用既有工作后的作者归纳，本轮不将它升级为新证明。

### 5.2 固定模型结果与开销

§4使用二维合成及三类图像数据，重点量是超矩形各边长的几何均值，即该超矩形体积的n次方根。几何均值和体积关联，但数值比率不同：在固定维数n中，几何均值比r对应体积比r的n次幂。不能把作者展示的均值比例直接叫体积倍数，不能跨不同维数直接用这些比例做总体性能排名。

§4.2明确不改原模型。因此这里更大认证区域意味着对既定安全空间更紧的内侧近似，不等于模型经本文变得更鲁棒。正常/鲁棒模型是评价中已有的两组模型，后者采用PGD训练；不应据其存在推断Amoeba引导训练已完成。

Table2将效能增益和计算代价一起交付。对某些CNN设置时间接近，对FCNN有额外代价。源文以MNIST100增加0.1秒作易懂例子，但表中还有SVHN300由4.01至4.79秒的non-uniform比较。若新稿需要说明开销，宜选择与主任务部署条件相关的对照并交代分布，不复制“可忽略”作全条件事实；同样不该从该行反过来否定所有设置的可用性。§6仍明确大模型、更多架构（如ResNet）、效率和像素相关性为后续工作。

### 5.3 应用证据不能被认证指标替代

威胁用途：§5.1以逃逸率与保留效用共同定义“更强”。Table4的MNISTLeNet C&W例在100%逃逸情况下，l1扰动依次为28.8、22.71、19.46，三项分别是原攻击、non-uniform引导和Amoeba引导。它能支持这个条件下更少总体扰动，却不能说明所有范数距离都更小：该行l2并未随l1一起变小。源文也写到部分l∞设置没有提升；另有更高逃逸而扰动微升的权衡。因而只摘最大成功率会遗漏任务判据，只摘低l1会遗漏成功条件。这里只讨论证据，不扩展攻击操作。

解释用途：§5.2真正需要的是左右界差，而非仅总宽；对称表示无法直接提供同一方向偏好量。作者在鲁棒模型上考察解释；fidelity主要是设计论证，stability用降维后聚类位置作定性观察，comprehensibility靠可视化例子说明。不能改称三项都经用户实验或标准化数值指标验证；也不能从小认证宽度直接严格推出域外必有对抗样本，因为保守认证域小不等于真实边界已近。这限制的是解释证据强度，不抹去方向量本身的新信息。

训练用途：§6给数值分类玩具例与潜力推断，尚不是训练方法加对照实验的结果包。这与C3.S4表面的强结果措辞不一致，应保留为证据状态边界。迁移时训练潜力可作为开放方向，不能挂在已完成实验贡献下。

## 6. 为什么这些贡献不应与三技术阶段同构

实际贡献为2／2／4个句式单位：概念、可用框架、下游用途。三个技术步骤共同实现框架；贡献不是将形式化、放松、优化原样改成三条。

- C1新增知识对象及其方向/幅度含义，依赖强近邻和受控例子，不能只报品牌或首次
- C2交付可用实现并用两种证据支持认证界。分析解释保证与对象关系，实验交实际解的表现；没有读到一个“每次近似求解必定比所有已有算法更紧”的比较定理
- C3前两句交两项应用与用途结果，后两句转向研究启发及训练实例。该项较长，是因为下游价值和完成状态仍需解释；长度不是值得机械复制的格式

源文在贡献前另有P7结果/意义段。它是这个历史来源的实际组织，不能被当前写作默认结构反向修写掉，也不能自动强迫新稿照搬。新稿若已在贡献外完整交实证结论，可在贡献里简洁归纳；若尚无读者前提，则需要补证据条件。条数与长度应由独立所得及已交解释决定。

## 7. 保义表达的情境选项（原创示范，不是原句引文）

每组选项对应同一问题的不同焦点；不是可随意互换模板。

A. 强近邻残余
- 已介绍non-uniform的读者：Non-uniform certificates allocate different widths across features, yet still tie each feature’s two directions to one radius.
- 尚未了解近邻的读者：Allowing one radius per feature resolves differences across features; a separate restriction remains because that radius extends equally in both directions.
- 若读者已懂几何，可直接命名中心对称限制；若尚未懂，第二种先承认能力再给残余。不能删第一能力而泛称existing certificates ignore heterogeneity。

B. 新对象的实际收益
- 需解释价值：At a fixed input, independent directional widths can retain safe space discarded by a centered interval.
- 需解释控制：Keeping the classifier and input fixed isolates the effect of releasing the equal-width constraint.
- 前者交研究所得，后者交例子的证据设计；两者不能互充。can也不能改成every approximate certificate strictly enlarges。

C. 方案后的计算代价
- 保留短停顿：The resulting program is costly to solve directly. We therefore build tractable sufficient conditions from layer-wise output bounds.
- 已熟悉优化的读者：To make this formulation tractable, we replace direct network constraints with conservative output-bound conditions.
- 第一种让新设计→代价→回应显形；第二种压缩但仍保“this”依赖。不能在方案出现前放resulting program，也不能把conservative写成exactly equivalent。

D. 两个设计理由
- 突出共同产物：The formulation gives each direction its own width and represents convolutional and fully connected operations natively.
- 读者需要分别回扣：Independent widths address directional asymmetry. Native layer constraints address the architecture interface.
- 第一种适合两个前提已解释；第二种适合读者还可能混淆两条因果。不能用therefore声称一个设计自然推出另一个。

E. 实证结论
- 研究主张在主句：For the evaluated models, Amoeba certifies larger regions with modest additional runtime.
- 需要证据框：Our comparisons evaluate both region size and runtime to test whether the richer representation remains usable.
- 前者是完成结果，后者是研究设计。modest只有在真实规模、预算及数据支持时可用；不能仅凭计划写第一句。

F. 联合应用判据
- 具体已证条件：In this comparison, directional guidance reduces total perturbation while retaining the same evasion rate.
- 若存在权衡：Some settings exchange a small increase in perturbation for a higher evasion rate.
- 二者都是可能有价值的结果，但命题不同；不能将第二种统一润色成without any loss。

G. 训练方向
- 对齐本稿实际证据：Directional certificates suggest a training objective that need not be limited by the smaller side alone.
- 只有补齐训练实验才可用：Training with the proposed objective improves the specified robustness and utility measures under the evaluated conditions.
- 后者不是当前源文足以支撑的改写，本轮不得采用。此处强调结果状态，而不是习惯性弱化所有主张。

## 8. 证据选取、舍弃与长度决定

最合适的材料取决于读者此刻缺哪条关系，而不是固定每段放几个数字。

- 定义新颖性争议：优先特例关系和受控一维例；复杂基准大数字不能单独隔离新增自由度
- 实际算法紧度：必须转向§4在相同模型/样本条件的认证结果；仅有可行域的概念包含不够
- 实际可用性：加入运行时间、架构和规模；不要把架构例子升级为一般网络承诺
- 威胁用途：选择同时保持/改变逃逸率与效用的具体对照，保non-uniform强基线；部分l∞无收益是适用条件，不应为漂亮结论删去
- 解释用途：选左右差值如何增加可解释方向的信息，说明观察型证据；不要列三个评价词就宣称三个完备测量
- 训练方向：保留潜力与玩具解释，舍弃未经证实的完成态结果措辞；不需要为凑结果再找当前文献替原文补证

引言不必放全部正文限定，但不能留下会被正文直接推翻的普遍断言。公式端点和表格数值冲突不适合当营销性数字；在源学习档案保留原冲突并选不受冲突影响的已核对照。这样的取舍是解释性编辑判断，不是实测写作收益。
