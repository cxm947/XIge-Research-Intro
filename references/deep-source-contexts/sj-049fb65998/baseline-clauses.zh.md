# IMMI逐句分句、语法及信息分配
保留的完整来源重建；其全部旧单元并未在本次定点审查中重新获得独立验证。当前选择分析与证据资格共同使用；相邻明确资格约束历史简述。 坐标P1–P10沿视觉论证段，P8–10为贡献；每项先列主谓骨架（中文释义）与分句关系，再列读者入→出及回收。不是源文翻译副本，未重复完整原句。页码物理1起算。

## P1 p.2右
S1 主语内核、系表基础组成；分词结构补其硬件/应用中介角色。入无对象→出关键系统位置；为内存用途缩焦
S2 内存资源为被动主语，三个用途并列，不同运行功能共享同一资源；结果分句解释不可缺。入内核→出内存对象；§2回收
S3 转折后复杂管理作主语、引入缺陷为谓语；三个错误类型为例而非完备集合。入有用→出为何值得检测
S4 缺陷主语、损害稳定性能谓语；方式分句给耗尽/不可预测，递进分句增加安全威胁。入错误→出运行后果
S5 利用行为主语、可能导致谓语；访问、提权、失陷由局部到整体。入稳定损失→出安全后果；情态保留可能性
S6 原因状语并列普遍性与危害，形式主语引必要性判断。入价值已知→出系统处理需求；此句不是具体方法空白

## P2 pp.2右–3左
S1 最直接方式作主语、静态追踪为表语；关系从句给用户态既有使用。入需要检测→出已有强答案
S2 两类条件定义对照：未释放与释放后再使用/释放；后者有未重新初始化限制。入追踪名→出何信息足够判错；生命周期成为后文比较基准
S3 转折主语换成该方法在内核的应用，被动受规模阻碍。入方法可行→出场景适用边界
S4 大代码库主语、引入过多路径谓语；括号规模例子→结果分词路径/状态爆炸。入边界→出原因；§4切片摘要回收

## P3 p.3左
S1 目的状语回指规模，工具作主语、改用配对谓语。入直接法太贵→出实用近邻
S2 内核主语、使用MM函数谓语；括号函数例子，目的为协调生命周期。入配对名→出资源管理接口
S3 函数被动意图谓语、协同执行；分词解释分配/释放阶段。入接口→出成对依据
S4 K-Meld/Hector主语、检测泄漏谓语；手段分句是检查缺失释放函数。入配对依据→出实际检测条件
S5 SinkFinder/NLP_EYE主语、利用函数谓语；目的从句简化损坏检测的数据流。入泄漏用途→出另一用途
S6 HERO主语、面向顺序错误的被动结构；关系从句限定不是一般内存错误。入函数是否齐全→出次序也重要
S7 对照连接词切到部分工具，使用相似性谓语，目的仍是规模。入配对→出不同路线
S8 IPPO/NDI主语、检测谓语；手段分句是语义类似路径的内存操作不一致。入相似名→出比较参照；P4才问参照存在与否

## P4 p.3左
S1 方法主语、已证明有效谓语；完成体承认已有成绩。入近邻→出正面基线
S2 转折、同主语仍有局限；只预告，不自成技术理由
S3 存在结构引第一个假设：配对函数实现自身正确。入有效→出有效性的隐藏条件
S4 此假设主语、并非总成立谓语；范围定位复杂内核。入假设→出需反例验证
S5 条件状语给内部缺陷，插入例说明释放未彻底；主句漏洞仍在，尽管配对用法正确。入抽象前提→出调用正确不足的反例；§6.5 LLM失败回收
S6 第二序词；方法依赖正确片段主句，目的两个并列：配对识别/相似分析。入内部正确性→出参照可得性这一不同前提
S7 工具主语、识别配对谓语；手段是常一起使用。入依赖参照→出统计来源
S8 相似连接词；四工具需至少一个正确释放过程内路径，目的保证检测。入频次→出路径参照；量词至少一条不可删
S9 原因状语专用代码多；许多路径独特主句；分词缺合适参照。入所需参照→出目标场景缺失；P6自主对象分析回应

## P5 p.3左末–右上
S1 既有研究表明主句；内存错误常在错误路径的内容从句；关系从句解释释放资源回滚状态。入参照缺口→出可聚焦的运行阶段
S2 理想情态+存在一致约定；关于谁在特定失败时释放对象。入错误处理→出正确关系
S3 观察为主语、共同根因为表语；让步插入保留症状不同；冒号定位所有权和生命周期模糊，时间条件是提前释放。入正确关系→出统一解释

当前语法资格（P5.S3）：严格矩阵是作者的关键观察是某个that内容命题；共同问题位于内容从句，despite承认症状差异，when限定情境。历史行保留正确的语义关系，但不把内容命题当作无归属的整句矩阵或普遍定理。
S4 指示代词回指模糊，尤其跨多函数共享时；条件限制价值面。入根因→出最相关对象
S5 举例条件：两方都认自己负责；结果可能重复释放/UAF，再到损坏。入责任→出第一失配后果
S6 对照条件：两方都不负责；资源仍占用主句与结果泄漏。入重叠→出空缺；同一关系覆盖第二症状
S7 总结存在结构命名不一致意图。入两个例子→出可复用概念；非新增事实

## P6 p.3右

S2 作者提出对象方法；插入LLM增强、目的推断意图。入判据→出分析单位和辅助工具
S3 共分析作主语、利用谓语；程序结构与语言元素并列，括号给注释/隐式机制。入工具名→出证据类型
S4 指示代词作主语、使推断成为可能；粒度和内核范围限定能力。入证据→出解释精度愿景；需要正文验证

当前归属资格（P6.S4）：源作者以enables提出精确推断、细粒度和内核范围的能力主张；“愿景”不能将其改成纯未来期望。该句本身不报告独立准确率，本轮也未据此认证完全正确。
S5 递加连接；作者提出切片/摘要，并列技术共享平衡目的。入精度→出成本控制
S6 IMMI主语、有优势谓语；列表预告不额外计研究成果
S7 推断需有限路径和调用链主句；结果分词无需长数据流。入方法→出对P2规模的回应
S8 IMMI独立于频繁/相似片段主句；结果保留定制代码适用。入少追踪→出对P4参照缺口的回应
S9 递加、不靠函数对；结果避开其约束。入前两优势→出对配对前提回应；不等于推断永不再犯同样错误
