# 选择证据与解释量

## 1. 先写研究答案，再取证明同一答案的结果

末评价项从实际评价工作起步，紧接一条有据的任务层所得，再取必要代表证据。先完整考虑结果全貌，选成立且最有意义的正面推进；若失效本身就是核心研究问题，它的发现就是答案。

区分终端任务、机制代理、部署代价、理论保证及现实确认状态，核对对象、分母、统计单位和比较条件。强近邻的真实能力保留；不要只挑最弱对手制造大差距。反向证据若改变主张范围，合入该句条件；若推翻它则缩窄或更换主张；若回答其他未宣称能力，留相应结果／讨论。

检验每个候选数字是否证明同一句任务答案。若换数字时必须偷偷换对象、启动条件、任务量或比较基线，它不是更好的同命题证据。效果和效用需要共同成立时保两轴，不能拼接不同设置的最佳格子。一个数字足够就用一个，所需两轴也不为短而删。

## 2. 聚合、明确标注的实例、跨条件定性答案

- 总体／通常收益，且任务量、预算、基线、比较单位相容并有来源明确的聚合：用合适聚合及范围。WAFLGO P8的平均速度回答及时commit测试的总体能力，单例359.9倍不能替代；不可自行平均不相容指标
- 具体能力例，且没有合适整体单值：可选明确标作实例的设置，保任务、对象和条件。TextShield C2的0.944是色情检测实例，模型组合与扰动上限要另查§5／Table4；不能推及全部模型／扰动，也不因最大而优先
- 主要答案是可用范围、观察对象或互补性质，分布异质：用有据跨条件定性答案，按需给严格限定锚点。FreeEagle P7.S8给同条件近邻比较，C3概括复杂后门检测及胜过部分有数据方法，没有挑单格100%。跨条件不等于处处赢

聚合不总优于实例，定性也不用于回避用户数字要求。用户需数字时从成立主张内挑能清楚定范围的锚点；无证据就指出具体缺证。

源选择的任务意义：UVSCAN终端违规判断比中间抽取分数更贴任务；IPPO确认新缺陷与接受补丁比报告总量更贴产出；InvMM的核心对象推进未必由最大AUC表达。这些只教取材，不给别的论文事实或数值。

## 3. 评价句怎样成文

先交做了什么范围的评价、得到什么任务答案，然后用必要事实让答案可见。主判断直接表达任务完成或改善；前文已建立的意义不再追加复述，新效用或真实确认状态仍应保留。方案直接接贡献且前文未报结果时，保留答案和代表证据；前文已充分报结果可归纳。使用[评价内容分支](choices/i-evaluation.md)及[语言操作L7](realizations/operations.md#l7)，不把“effectiveness”孤立当答案。

数字附近保留理解本句主张所需的对象、指标、基线、方向、分母及条件；已在前文明确且可恢复的信息不必重复。某一配置下已达到的实验结果不自动承诺各配置都达到同一数值，影响所报数值的设置也不自动都需写入引言；不决定本句主张含义的复现细节留方法／评价部分，所选证据及其来源位置仍按[L7](realizations/operations.md#l7)记在稿外。定理假设、威胁尺度和真实比较条件若决定本句含义，仍须随主张交代；不能因移走条件而扩大或反转结论。reported、detected、confirmed、fixed、CVE是不同状态，子集关系不能扩大。结果动词也须核对：识别数不等于恢复数。研究答案由作者口吻直接陈述，完整核对池留稿外。

## 4. 长度由未完成的解释职责决定

本位置还需承担什么：对象初定义、原因、任务后果、方法接口、比较轴、成立条件或代表证据？先删邻句已经完成的重复，再保住接受本地判断所需关系。要压贡献中的方法细节，先将首次解释移到方案段，不能单纯删掉。

对照同职责、同前文解释量来源：

- FreeEagle C1–C3为22／25／26词，P6/P7已用85／199词解释机制；短项有前文承担
- FirmRCA C3为74词／3句，因前文未完整预告结果，本项承担范围与主要答案
- InvMM C1为130词／4句，兼做方案、对象、约束和尺度定义；有独立方案段的新稿宜先迁移这些解释

这些是特定版本的定位性计数，按来源坐标中列明口径使用，不生成短中长配额或目标平均词数。拆句多回指，合句可能降低独立推进显著性。长度变化需说明多交了什么判断、少了什么重复或移动了哪项职责，不把字数减少当质量证明。

可选对照：[TFA选证位置实例](deep-source-contexts/sj-23809d776d/evidence-choice-example.zh.md)把挑战中的剩余负担统计、可留背景的小例与可留评价的组件消融并置，说明各自删移会失去什么；只在当前取舍需要时读。

## 5. 根据所选源回查必要上下文

至少读目标段、必要邻段和完整贡献集合；重要数字另读正文位置。写短贡献前问前文是否已完成它省略的解释；用正文发现前移时区分源Intro实际内容与编辑选择。[来源目录](../data/source-index.json)保存版本和已读范围，不能用未读补充证明主张。
