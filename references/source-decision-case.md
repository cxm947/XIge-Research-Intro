# 在源例的分岔处选择下一段：Amoeba

这是一张可选的写作来源卡，供“同一个更大／更细结果究竟改变了什么”尚不清楚时使用。它不替本稿选研究主张，也不提供目标论文的技术事实。

来源为 [Amoeba 作者托管稿](https://nesa.zju.edu.cn/download/lcj_pdf_tdsc21.pdf)，完整 Introduction 在 PDF 1–2 页；独立方向参数和恢复旧对象的条件另在 §3.2.1、PDF 3–4 页。以下续写分岔是编辑分析，非作者的选题自述。使用前连读完整引言。

## 决策现场

读者已经知道认证要给定输入附近的可靠范围；近邻已经允许不同特征有不同半径。若只留下“更细粒度”“更大范围”，下面两种下一段都会貌似合理：

- 继续解释怎样更准确地计算同一种允许区域，再介绍新求解器
- 先说明允许区域本身还固定了哪个关系，再解释为何放开它，随后介绍求解器

源文用一个固定模型、固定输入的一维例子区分它们：离输入两侧区域边缘的距离并不相等，而前述两类区域仍要求正负方向等距。即使把对称范围算得更准，等距关系仍在。因此此处先介绍正负方向独立取界，才进入形式化、松弛和求解。§3.2.1 中令两侧参数相等可恢复非均匀对象，再令各特征相等恢复均匀对象，这进一步说明改变的是哪项自由度。

这里应当借走的是“固定其余对象，用一个能区分两条续写的事实决定下一段解释什么”。不能只借“先写例子”，也不能把方向不对称、区间数字或该方法的新颖性移入另一篇论文。若本稿仍用同一种允许区域、只是估计更紧，第一条续写可能才对；没有区分事实时，保持已有范围并另查关键关系，不用源例代填。

## 如何在本稿落笔

遇到上述分岔时，从本稿材料选出那项能排除一条续写的关系，然后直接起草其支持的下一段。文字应使读者看清：哪些对象或条件保持不变、哪个关系决定了当前的研究动作。不要求正文出现分岔列表或固定句式。若该源例没有改变本稿的内容选择，跳过它；不要增加一段“洞察”来证明读过来源。
