## Nearby method/evaluation checks

Checked §II (PDF pp.2–3): prediction gives function probabilities; basic blocks receive static vulnerable scores, and input fitness sums executed block scores. Checked §VI (PDF p.7 onward): prediction and fuzzing evaluated separately, with memory-related Juliet samples and real-world CVE labeling. Checked limitations (PDF p.10): limited training data, function-level granularity, and extensible-framework rather than perfect prediction. Soft weighting in the Introduction is motivated by this fallibility.
